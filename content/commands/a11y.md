## Launching A11y Agent

The a11y agent will:
1. **Detect frontend framework** — React, Vue, Svelte, plain HTML, etc.
2. **Scan components** for WCAG violations (A, AA, AAA level)
3. **Check** — Images, forms, navigation, headings, ARIA, keyboard, color, focus management
4. **Generate a severity-ranked report** with file:line references and fixes
5. **End with fix options**: report only, fix auto-fixable issues (missing alt text, missing labels, ARIA attributes), fix all, or create a fix plan (`{{PLANS_DIR}}/PLAN_A11Y_FIXES.md`)

**Workflows**:
- No argument → Scan all frontend files, report violations ranked by severity
- `[file or component]` → Focused audit on that specific file or component
- `AA` or `AAA` → Target a specific WCAG conformance level
- `fix` → Auto-fix all auto-fixable issues after presenting the report

<!-- claude-only -->
**All frontend files or a folder, as a workflow**: with no argument, a WCAG level, `fix`, or a folder path, and the `Workflow` tool available, run the saved workflow **`sweep`** instead of the agent, with args `{ "kinds": ["a11y"] }`, plus `"scope"` for a WCAG level and `"paths"` for a folder. It splits the UI code into areas and scans them in parallel, and a separate agent checks every finding. It changes nothing. Wait for the completion notification, then show its result as the report: the `confirmed` findings grouped by severity with their ids; `unverified` ones separately, flagged as unchecked; how many were `dropped` as false positives; and any `missingScanners` (areas that weren't scanned), `skipped` areas and `leftOut` count. With `fix`, then launch the a11y agent with the `confirmed` findings marked `autoFixable` (not the unverified ones) and "Fix these findings — don't re-audit"; otherwise continue with **When the agent returns**. For a single file or component, or when the workflow isn't available or the run fails, launch the agent:

Use the `Agent` tool to launch the a11y agent (subagent_type="a11y") with the scope and any additional context. With the `fix` argument, tell it to apply the auto-fixable fixes after reporting.

**When the agent returns** (without `fix`): show the user its report, then ask which option they want with `AskUserQuestion` (the agent runs as a subagent and can't ask). For a fix or fix-plan option, relaunch the a11y agent with the reported findings and "Fix these findings — don't re-audit" (naming which findings, per the chosen option), so it doesn't scan everything again.
